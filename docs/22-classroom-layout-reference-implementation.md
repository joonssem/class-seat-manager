# 이미지 기준 교실 배치 적용 기록

작성일: 2026-09-01

## 변경 내용

- 칠판을 상단에 배치했다.
- 앞문과 뒷문을 오른쪽에 배치했다.
- 좌석 1~21을 이미지 기준 좌표로 구성했다.
- 좌석 1은 좌석 5·9·13·17·21보다 위쪽에 배치했다.
- 교실 저장 시 기존 요소를 삭제하지 않고 upsert하며, 참조 중인 좌석은 비활성화해 외래키 오류를 방지한다.
- 자리번호가 과거 기록과 일치하도록 `seat-1`부터 `seat-21` ID를 유지한다.
