# 모둠 자리표 방향과 5모둠 배치

작성일: 2026-10-22

- 각 모둠의 책상 좌표와 가로·세로 크기를 시계방향 90도 회전한다. 이름·번호 텍스트는 회전하지 않는다.
- 5명인 5모둠은 가장 뒤쪽에 유지하고, 나머지 모둠의 좌우 외곽 기준 가운데에 정렬한다. 인쇄 영역 맞춤 후에도 가운데가 유지되도록 모둠 좌표에는 개별 줄 정렬을 적용하지 않는다.
- 5모둠의 5번 자리가 가장 뒤 단독 자리가 된다. 새 모둠 생성 및 확정 시 이 자리를 남학생에게 배정하는 것을 필수 조건으로 평가한다. 모둠 전체의 남학생 수를 1명으로 제한하지는 않는다.
- 기존 모둠 자리표도 조회할 때 회전과 중앙 정렬이 적용된다. 이미 회전한 좌표는 다시 회전하지 않는다. 교사용은 학생용과 일치하는 배치를 180도 반전한다.
- 기존 저장 기록의 학생 배정은 자동으로 바꾸지 않는다. 기존 5번 자리에 여학생이 있다면 모둠을 새로 생성하거나 수동 교환 후 확정해야 한다.
- 비모둠 자리표는 기존 표시 규칙을 유지한다.

회전 방향, 학생 이름·번호 보존, 중복 회전 방지, 인쇄 맞춤 후 5모둠 중앙 정렬, 맨 뒤 자리 남학생 조건과 수동 교환 후 재평가를 테스트한다.
