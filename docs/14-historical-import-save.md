# 1학기 과거 자리 기록 저장 구현 기록

작성일: 2026-09-01

## 구현 내용

- 5회차 전체를 검증한 뒤 저장하는 `confirmBatch` 경로 추가
- 학기별 회차 번호를 기존 기록 다음 번호부터 계산
- 5회차 session과 assignment를 하나의 SQLite transaction으로 저장
- 중간 오류 발생 시 전체 rollback
- 자리 기록 화면의 미리보기에서 검증 성공 후 저장 버튼 표시
- 1학기 기록은 `semester=1`로 저장

## 안전성 기준

- 미등록 학생·동명이인·없는 자리·중복 배정은 저장하지 않는다.
- 배치일은 `YYYY-MM-DD` 형식이어야 한다.
- 학생과 자리는 현재 명단·layout의 ID로 저장한다.
- 기존 확정 기록과 snapshot은 변경하지 않는다.

## 검증 결과

- 타입 검사 통과
- 전체 테스트: 22개 통과, 1개 스킵
- 프로덕션 빌드 통과

## 사용 흐름

1. 자리 기록 화면에서 1~5회차 입력
2. 각 회차의 배치일 입력
3. `5회차 매칭 미리보기` 실행
4. 모두 성공하면 `5회차 기록 저장` 실행

저장 후 1학기 기록은 자리 기록·학생별 통계·2학기 추천의 과거 이력에 사용된다.
