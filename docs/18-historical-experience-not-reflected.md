# 과거 자리 기록 학생별 경험 미반영 오류 기록

작성일: 2026-09-01

## 사용자 제보

- 1학기 과거 자리 기록을 입력·저장했으나 `학생별 자리 경험`에 반영되지 않는다.
- 이번 단계에서는 코드 수정이나 데이터 재저장을 하지 않는다.

## 기대 동작

- 1학기 과거 기록 5회가 저장되면 학생별 자리 경험 통계에 해당 회차의 자리 위치가 누적되어야 한다.
- 전체 조회에서는 1·2학기 기록이 함께 집계되어야 한다.
- 1학기 필터에서는 1학기 기록만 집계되어야 한다.

## 점검 대상

1. 과거 기록 저장 후 `seating_session`과 `seating_assignment`가 실제로 생성되었는지 확인한다.
2. 학생별 경험 집계 쿼리가 `seat_position_tag` 또는 자리 snapshot 중 어떤 데이터를 기준으로 하는지 확인한다.
3. 과거 기록의 `seat_id`와 경험 집계가 조회하는 좌석·위치 정보의 연결을 확인한다.
4. `semester` 필터가 저장된 1학기 session을 제외하고 있지 않은지 확인한다.
5. 저장 직후 화면의 `experience` 재조회가 실행되는지 확인한다.
6. 집계 결과의 학생 ID와 현재 학생 목록의 ID가 일치하는지 확인한다.

## 처리 상태

- 버그 기록만 완료
- 코드 수정 보류
- 원인 확인 및 수정은 별도 승인 후 진행

## 재제보

- 과거 1학기 5회차 입력 후에도 `학생별 자리 경험`에 5회 기록이 반영되지 않는 상태가 계속된다.
- 이전의 단순 미반영 제보가 해결되지 않았으므로, 저장 성공 메시지 여부와 무관하게 실제 DB의 session·assignment·좌석 위치 집계 결과를 함께 대조해야 한다.
- 다음 원인 확인 시 `seat_position_tag`가 비어 있는 좌석의 처리, `seat`와 `classroom_element`의 ID 연결, 학생별 경험 조회의 학기 필터 및 재조회 시점을 우선 확인한다.

## 진단 결과

- 저장 경로의 `position_snapshot_json`에는 현재 `x`, `y`, `width`, `height`, `positionOverride`만 저장된다.
- 학생별 경험 집계는 snapshot에서 `vertical`과 `horizontal` 값을 읽어 `앞/중간/뒤`, `왼쪽/가운데/오른쪽` 횟수를 증가시킨다.
- 과거 기록 저장(`confirmBatch`)과 일반 확정 저장 모두 snapshot에 `vertical`·`horizontal`을 넣지 않으므로, 집계 쿼리는 실행되어도 위치 카운트가 모두 0으로 남는다.
- 따라서 이번 현상은 학기 필터나 화면 재조회보다 저장 snapshot의 위치 태그 누락이 직접 원인으로 판단된다.
- 수정 시 현재 책상 좌표와 문 위치를 기준으로 계산한 `SeatPosition`을 snapshot에 함께 저장하고, 기존에 저장된 과거 5회차 데이터는 snapshot을 보정하거나 재입력해야 한다.

## 적용 결과

- 일반 자리 확정과 과거 기록 일괄 저장 시 `SeatPosition`을 snapshot에 함께 저장하도록 수정했다.
- 기존 snapshot에 위치 태그가 없는 기록은 현재 학년도의 자리 구성표에서 좌석번호에 대응하는 책상 좌표와 문 위치를 사용해 집계 시 보완한다.
- 따라서 현재 자리번호가 과거 기록과 일치한다는 전제에서 기존 1학기 5회차도 별도 재입력 없이 학생별 경험 통계에 반영된다.
- 타입 검사 통과, 전체 테스트 25개 통과·1개 스킵, 프로덕션 빌드 통과.
