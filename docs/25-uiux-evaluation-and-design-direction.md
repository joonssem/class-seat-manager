# 후보 평가 표시 진단 및 UI·UX 디자인 방향

작성일: 2026-09-01

## 평가 적용·표시 진단

| 조건 | 엔진 적용 | 현재 화면 표시 | 진단 |
|---|---|---|---|
| 같은 자리 반복 | 적용 | `같은 자리 반복` penalty | 표시됨 |
| 과거 근접 반복 | 적용 | `반복 근접` penalty | 표시됨 |
| 성별 인접 | 적용 | `성별 인접` penalty | 표시됨 |
| 학생 위치 조건 | 적용 | 미충족 시 reason, penalty | 충족 조건은 별도 확인 불가 |
| 학생 pair 거리 | 적용 | 미충족 시 reason, penalty | pair별 대상·현재 거리 미표시 |
| 가능한 한 멀리 | 적용 | `학생 pair 거리` penalty | 어떤 pair에 적용됐는지 미표시 |
| 필수 조건 | 적용 | hard violation 또는 만족 문구 | 어떤 필수 조건을 검사했는지 요약 부족 |

## 결론

- 후보 점수와 6개 penalty 항목은 렌더링된다.
- 그러나 현재 `평가 설명`은 위반 reason만 표시하며, 조건이 만족된 경우나 적용된 학생·pair 목록을 표시하지 않는다.
- 따라서 “모든 조건이 적용되었는가”를 사용자가 화면만 보고 검증하기 어렵다.
- 특히 `가능한 한 멀리`는 점수에는 반영되지만 pair별 거리와 기준 최대거리가 표시되지 않는다.

## UI·UX 개선 방향

1. 후보 상단에 총점, hard 조건 통과 여부, 적용 조건 수를 함께 표시한다.
2. 평가 항목을 `자리 이력`, `학생 위치`, `학생 pair`, `성별 인접` 그룹으로 나눈다.
3. 각 항목에 penalty뿐 아니라 짧은 설명을 표시한다.
4. pair 조건은 학생 이름, 현재 거리, 기준(최소거리/가능한 한 멀리), 강도를 표시한다.
5. 만족·주의·위반 상태를 색상과 아이콘·문구로 동시에 표시한다.
6. 배치표와 평가 설명을 같은 화면에서 비교할 수 있도록 유지한다.
7. 학생 교체 후 “재평가 필요” 상태를 표시하고, 저장 전 최신 점수를 다시 계산한다.

## 디자인 토큰 방향

- 기본 배경: 밝은 회색, 카드: 흰색, 테두리: 연한 청색 회색
- 주요 행동: 파란색
- 만족: 녹색, 주의: 주황색, 오류/필수 위반: 빨간색
- 제목·학생명: 높은 대비와 굵은 글꼴
- 좌석: 번호와 학생명을 함께 표시하고 선택 좌석은 두꺼운 테두리로 강조
- 한 화면의 주 행동은 `후보 생성`, `수동 수정으로 이동`, `확정` 순서로 명확히 둔다.
