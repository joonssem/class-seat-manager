# 교실 저장 외래키 오류 기록

작성일: 2026-09-01

## 사용자 재현 오류

- 개발 앱에서 교실 설정을 저장할 때 `classroom:save` handler가 실패한다.
- 오류: `SqliteError: FOREIGN KEY constraint failed`
- 발생 위치: `SqliteClassroomRepository.save`
- 동일 오류가 연속 3회 출력되었다.
- 이번 단계에서는 코드 수정이나 데이터 삭제를 하지 않는다.

## 현재 판단

- 최근 책상 요소와 `seat` 레코드를 함께 동기화하도록 변경한 뒤 발생했다.
- 교실 저장은 기존 `classroom_element`를 먼저 삭제한 다음 새 요소를 저장하는 구조다.
- 기존 `seat.element_id` 또는 `seating_assignment.seat_id`가 기존 책상 요소를 참조하고 있으면, 요소 삭제 시 외래키 제약에 걸릴 가능성이 있다.
- 정확한 실패 SQL은 빌드 산출물의 줄 번호만으로 확정하지 않는다.

## 수정 전 확인 계획

1. 현재 DB에서 `seat`, `classroom_element`, `seating_assignment` 간 참조 관계를 조회한다.
2. 저장 트랜잭션에서 실패하는 SQL의 순서를 소스 기준으로 분리한다.
3. 기존 확정 이력을 보존하면서 교실 요소를 갱신할 수 있는 동기화 정책을 정한다.
4. 이미 이력에서 참조하는 좌석은 삭제하지 않고 비활성화하거나, 좌석·요소 ID를 안정적으로 유지하는 방식을 검토한다.
5. 수정 후 기존 이력 보존, 교실 재저장, 과거 기록 저장을 함께 회귀 테스트한다.

## 처리 상태

- 버그 기록만 완료
- 코드 수정 보류
- 원인 확인 및 수정은 별도 승인 후 진행
