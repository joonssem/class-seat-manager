## 적용 내용

- 자리 기록 조회가 배치일, 저장 시각, 회차 순으로 정렬된다.
- 자동 추천 이력은 오래된 배치부터 최신 배치 순으로 전달된다.
- 현재 자리 표시는 회차가 아니라 배치일과 저장 시각 기준으로 최신 기록을 선택한다.
- 자리 기록과 학생별 경험 통계에 전체/1학기/2학기 필터를 적용했다.
- 필터는 IPC, preload, service, repository, renderer에서 같은 학기 기준을 사용한다.
