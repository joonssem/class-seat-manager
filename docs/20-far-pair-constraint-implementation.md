# 학생 pair ‘가능한 한 멀리’ 로직 구현 기록

작성일: 2026-09-01

## 변경 내용

- 모든 활성 좌석 쌍의 중심점 거리 중 최댓값을 기준 거리로 계산한다.
- 지정된 pair의 현재 좌석 거리가 짧을수록 `1 - 현재거리/최대거리` 패널티를 적용한다.
- 조건 강도에 따라 패널티 배수를 적용한다.
- 자동 후보 생성과 후보 평가가 동일한 `pairDistance` 점수를 사용한다.
- ‘가능한 한 멀리’는 절대 임계값이 없으므로 hard violation이 아니라 상대적 최적화 조건으로 처리한다.

## 검증 결과

- 가까운 좌석 배치가 먼 좌석 배치보다 높은 pair 거리 패널티를 받는 테스트 추가
- 타입 검사 통과
- 전체 테스트 25개 통과·1개 스킵
- 프로덕션 빌드 통과
