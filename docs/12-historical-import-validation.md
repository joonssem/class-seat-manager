# 과거 자리 기록 입력 검증 구현 기록

작성일: 2026-09-01

## 이번 단계

P0 첫 단계로 학생 이름 + 자리 번호 입력을 해석하고 현재 학년도 학생·교실 자리와 매칭하는 domain 검증 계층을 추가했다.

## 지원 입력

```text
학생 이름<TAB>자리 번호
학생1<TAB>01
학생2<TAB>seat-02
```

- 탭 또는 쉼표 구분을 지원한다.
- 선택적 헤더를 무시한다.
- `01`, `seat-01`, `좌석 01`을 같은 자리번호로 정규화한다.

## 검증

- 미등록 학생
- 동명이인
- 존재하지 않는 자리
- 학생 중복 배정
- 자리 중복 배정

## 검증 결과

- 타입 검사 통과
- 과거 입력 파서·매칭 테스트 2개 통과
- 실제 1학기 데이터 저장은 아직 진행하지 않음

다음 단계는 이 검증 결과를 5회차 미리보기 화면에 연결하는 것이다.
