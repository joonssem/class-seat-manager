# 학급 자리배치 도우미 UI/UX 개선 구현 기록

작성일: 2026-09-03
기준 문서: `학급자리배치도우미_UIUX_개선지시서_codex.md`

## 적용 내용

- 시안 A(차분한 남색)를 기준으로 디자인 토큰, 포커스 표시, reduced-motion 대응을 추가했다.
- 공통 `Button`, `StatusBanner`, `EmptyState`, `SegmentedControl`, `ConfirmDialog`, `Card`, `SectionHeader`, `StatusPill`, `Toast`, `InlineError`, `SeatCell` 컴포넌트를 추가했다.
- 대시보드의 준비 부족 상태에서 학생 명단 또는 교실 설정으로 바로 이동하도록 개선했다.
- 새 자리 만들기에 빈 상태, 생성 상태 안내, 후보 성격, 점수 방향 설명, 좌석 교체 단계 안내, 평가 상세 접기를 적용했다.
- 수동 자리배치에 저장 상태, 초기화 확인, 저장하지 않은 이탈 확인, 확정 저장 토스트를 적용했다.
- 학생 관리에서 단일 학생 추가와 명단 붙여넣기를 분리하고 전출 처리 확인 단계를 추가했다.
- 교실 편집에 저장 상태, 요소 범례, 좌석 선택 키보드 접근, 좌석 삭제 확인, 저장하지 않은 이탈 확인을 적용했다.
- 자리표 보기 전환을 세그먼트 컨트롤로 통일하고 A4 인쇄 여백, 좌석 셀 가독성, 인쇄용 테두리를 보강했다.
- 급식실 결과표는 오른쪽 줄을 위에서부터 1~11번(1번 담임교사), 왼쪽 줄을 위에서부터 12~22번으로 표시하도록 열 순서를 조정했다. 평소에는 학생과 인솔 후보를 모두 `2~22번`에 무작위 배치한다.
- 인솔 후보 4명 중 2명을 무작위로 다시 골라 인솔자 위치를 확인하는 버튼을 추가했다. 버튼을 누르면 원래 자리가 비워진 뒤 두 인솔자가 순서대로 이동하며, 인솔자 자리는 `2번·22번`이다. 기본 줄서기와 인솔자 이동 결과 모두 pair 조건 평가를 표시한다.
- 급식실에서 마주보는 두 자리는 같은 줄의 옆자리와 별도로 직접 대면하는 가까운 자리로 계산한다. 따라서 모든 pair 유형의 점수에 마주봄 패널티가 반영되고 결과 상세에도 표시된다.
- 교실 자리표 인쇄는 A4 가로 방향으로 고정하고 좌석 이름의 줄바꿈을 방지했다.
- 오류·성공 메시지에 `alert`/`status` 역할을 적용했다.
