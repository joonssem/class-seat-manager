# 점수 체계·모둠·최소 거리 점검과 수정

작성일: 2026-10-01

## 방법
실제 사용 데이터(학생 21명·남 9, 이력 5회, 짝 조건 8개, 좌석 21개)의 사본으로 후보 생성을 시뮬레이션해 항목별 값을 확인했다(읽기 전용 사본, 학생 이름은 사용하지 않음).

## 발견한 문제와 수정
| 문제 | 증상 | 수정 |
|---|---|---|
| 점수가 0으로 눌림 | 후보 3개가 모두 0점. 항목 단위가 달라 위치 경험(원점수 약 180×가중치 15)이 총점을 지배하고, 점수 분모는 학생 수×100으로 고정 | 항목별 감점을 **무작위 배치 대비 비율**로 정규화한 뒤 가중합. 무작위 0점, 감점 없음 100점. 기준이 0인 항목(이력·조건 없음)은 점수에서 제외 |
| 위치 경험이 상수 | 문 근처가 아닌 자리끼리도 "같은 태그"로 세어 거의 모든 자리가 겹침 | 문 근처 태그는 true인 경우만 반복으로 계산 |
| 최소 거리 조건이 항상 위반 | 저장된 `최소 거리 2` 3건이 교실 좌표 거리(0~1.2)와 비교되어 어떤 배치도 만족 불가 | 최소 거리를 **자리 칸 수**로 계산(옆자리·앞뒤 1, 한 자리 건너뜀 2). 입력창에 단위 안내 추가 |
| 모둠 옵션을 켜도 한 성별 줄 | `여여여여여`·`남남남남남` 줄이 나옴. 감점이 약하고 기울기가 없어 탐색이 벗어나지 못함 | 모둠마다 성별별 기대 인원 미달을 단계적으로 감점, 한 성별만 있으면 추가 감점(가중치 25) |
| 생성이 느림 | 실데이터에서 약 13초 | 이력 집계·좌석 관계·짝 조건 색인을 입력당 1회만 계산(약 2초) |
| 항목 값 표시 | 단위 없는 원점수(181.49 등) | 화면에 무작위 대비 %로 표시 |

## 수정 후 결과 (실데이터 사본)
- 모둠 옵션 끔: 점수 56~57, 짝 거리 0(조건 만족), 위치 경험 0.70~0.82
- 모둠 옵션 켬: 점수 49~50, 모든 줄에 두 성별 모두 포함, 옆자리 같은 성별 1쌍
- 생성 시간 약 2~2.6초

## 한계
- `과거 근접 반복`은 0.8대에서 더 내려가지 않는다. 탐색 횟수를 4배로 늘려도 같아 구조적 한계이며, 성별 인접(가중치 40)과 충돌한다. 이력 5회로 학생 쌍 대부분이 한 번씩 가까이 앉았기 때문이다.
- 점수는 "무작위 대비 개선"이며 학생 구성상 피할 수 없는 감점이 있으면 100점에 못 미친다.
