# 새 자리 만들기 후보 점수 미표시 오류 기록

작성일: 2026-09-01

## 사용자 제보

- `새 자리 만들기`에서 후보 3개가 생성되지만 각 후보의 점수가 화면에 보이지 않는다.
- 이번 단계에서는 코드 수정이나 후보 생성 로직 변경을 하지 않는다.

## 기대 동작

- 후보 A·B·C 탭에 각 후보의 평가 점수가 표시되어야 한다.
- 후보 상세 화면에서도 선택 후보의 점수와 평가 항목을 확인할 수 있어야 한다.

## 점검 대상

1. `seating:generate` IPC 응답에 `evaluation.score`가 포함되는지 확인한다.
2. 후보 생성 후 renderer의 `candidates` 상태가 실제로 3개 평가 결과를 보존하는지 확인한다.
3. 후보 탭의 점수 표시 조건과 CSS 색상·가시성 문제를 확인한다.
4. 점수 값이 `undefined`, `NaN` 또는 0일 때 렌더링이 누락되는지 확인한다.
5. 후보 평가 객체의 타입과 실제 반환 구조가 일치하는지 확인한다.

## 처리 상태

- 버그 기록만 완료
- 코드 수정 보류
- 원인 확인 및 수정은 별도 승인 후 진행

## 재제보

- 후보 생성 후에도 후보 점수가 화면에 보이지 않는 현상이 계속된다.
- 이전에 점수 영역과 조건 요약 UI를 구현했으므로, 다음 확인에서는 실제 Electron renderer가 최신 `out/renderer` 번들을 로드하는지와 `evaluation.score` 값이 IPC 응답에서 화면 상태까지 전달되는지를 우선 확인한다.
