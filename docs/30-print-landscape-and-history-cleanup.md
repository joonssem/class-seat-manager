# 자리표 가로 인쇄, 과거 기록 입력 정리, 학기 자동 분류

작성일: 2026-10-01

## 자리표 인쇄 방향
- 증상: 학생용·교사용 자리표를 인쇄하면 세로로 나온다.
- 원인: 화면의 `window.print()`는 용지 방향을 앱이 보장하지 못한다(인쇄 대화상자 기본값이 쓰임). CSS `@page { size: A4 landscape }`는 있었지만 인쇄 대화상자 경로에서는 적용되지 않을 수 있다.
- 수정: 인쇄를 메인 프로세스로 옮겨 방향을 명시한다.
  - `print:page` → `webContents.print({ landscape: true, pageSize: "A4", printBackground: true })`
  - `print:save-pdf` → `printToPDF({ landscape: true, preferCSSPageSize: true, ... })` 후 저장 대화상자
  - 화면 버튼: `인쇄 (A4 가로)`, `PDF로 저장`
- 검증: Electron `printToPDF`로 앱의 인쇄 스타일을 출력해 모든 옵션 조합이 가로(A4 842×595pt)임을 확인했다. 실제 프린터 대화상자 경로는 자동 검증하지 못했다(직접 확인 필요).
- 급식실 화면의 `window.print()`는 변경하지 않았다.

## 학기 자동 분류
- `domain/semester.ts`: 배치일 3~8월 → 1학기, 9월~2월 → 2학기.
- 수동 자리배치: 학기 선택 제거, 배치일 옆에 "N학기로 자동 분류" 표시, 확정 저장에 자동 분류된 학기 전달.
- 과거 기록 입력: 학기 선택 제거, 배치일로 분류.

## 과거 기록 입력
- 5회차 입력 → 1건 입력으로 축소. 자리 기록 화면 하단에서 접힌 "과거 자리 기록 1건 추가 (필요할 때만)" 항목으로 이동.
- 저장 API(`history:import-historical`)는 그대로이며 1건을 전달한다.

## 자리표 인쇄 디자인 정리
- 문제: 책상이 교실 캔버스의 왼쪽 75%에 몰려 인쇄가 한쪽으로 치우치고, 칠판이 따로 고정되어 앞줄 책상과 겹치며(교사용), 용지 아래쪽 약 20%가 비었다. 열 간격은 손으로 놓은 좌표 그대로라 들쭉날쭉했다.
- 수정(`domain/seat-chart.ts`):
  - `regularizeSeatChart`: 같은 줄·열의 좌석을 한 선에 맞추고, 간격이 중앙값의 ±25% 이내면 균등하게 편다(복도처럼 의도적으로 넓힌 간격은 유지).
  - `fitSeatChart`: 좌석 외곽 상자를 구해 표시 영역 가운데로 옮기고 확대한다(가로·세로 확대 차이 최대 1.3배).
- 레이아웃: 제목(자리표 종류·기준·출력일) → 칠판(학생용은 위, 교사용은 아래, 좌석 영역과 분리) → 좌석 영역. A4 가로 한 장에 맞춘다.
- 글자: 번호는 작게, 이름은 크게(인쇄 16pt) 두 줄로 표시. 빈 자리는 점선·회색.
- 검증: Electron `printToPDF`로 학생용·교사용 모두 1쪽 A4 가로 PDF가 생성되는 것을 확인하고 인쇄 미디어 화면을 눈으로 확인했다.
