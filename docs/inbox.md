# 다음 수정 계획

이 문서는 프로그램을 검토하며 발견한 문제와 다음 수정 계획을 기록하는 공간이다.

## 첫 화면 UX/UI 개선

검토 자료: `capture001.png`

### P0 — 상태와 주요 행동을 일치시키기

- 현재 상단의 `2026학년도 준비 중입니다` 문구는 학생 21명과 확정된 자리 배치가 존재하는 상태와 모순된다.
- 데이터가 있으면 `학생 명단 입력` 대신 `학생 명단 수정` 또는 `학생 명단 관리`로 표시한다.
- 필수 준비가 완료되면 상태를 `자리 생성 준비 완료`로 표시한다.
- 준비가 부족하면 학생 등록, 교실 설정, 조건 설정 중 부족한 항목을 구체적으로 안내한다.
- 핵심 기본 버튼은 `새 자리배치 만들기`로 변경한다.

완료 조건:

- 실제 데이터 상태에 따라 안내 문구와 버튼 레이블이 달라진다.
- 사용자가 첫 화면에서 다음 행동을 바로 판단할 수 있다.

### P0 — 자리 생성 기능을 첫 화면의 핵심 행동으로 강조하기

- 현재 연한 보조 버튼인 `자리 생성`을 가장 눈에 띄는 기본 버튼으로 변경한다.
- 현재 배치가 없으면 `첫 자리배치 만들기`, 기존 배치가 있으면 `새 자리배치 만들기`로 표시한다.
- 준비되지 않은 경우 버튼을 비활성화하고 부족한 설정을 함께 표시한다.

완료 조건:

- 첫 화면에서 자리 생성 버튼이 가장 높은 시각적 우선순위를 갖는다.
- 비활성 상태의 이유와 해결 방법이 함께 표시된다.

### P1 — 정보 구조 재편

- 동일한 크기로 나열된 카드를 목적별로 재구성한다.
- 권장 순서는 다음과 같다.
  1. 현재 상태 요약
  2. 새 자리배치 만들기
  3. 준비 설정: 학생 명단 → 교실 배치 → 자리배치 조건
  4. 현재 자리: 미리보기, 인쇄, 수정
  5. 기록 및 기타: 자리 기록, 급식실, 급식실 기록
- 급식실 기능은 별도 섹션이나 상단 메뉴로 분리하는 방안을 검토한다.

완료 조건:

- 핵심 작업과 보조 기능이 시각적으로 구분된다.
- 일반적인 자리배치 작업을 위해 탐색해야 하는 카드 수가 줄어든다.

### P1 — 준비 상태를 실제 데이터로 표시하기

- 추상적인 초록색 점과 `준비 중` 대신 다음 항목을 체크리스트 또는 요약 지표로 표시한다.
  - 학생 21명 등록 완료
  - 교실 좌석 수 설정 완료
  - 배치 조건 설정 완료
  - 최근 자리 확정일
- 상태는 색상만으로 전달하지 않고 아이콘과 텍스트를 함께 사용한다.

완료 조건:

- 사용자가 무엇이 완료됐고 무엇이 남았는지 한눈에 알 수 있다.
- 색상을 구분하지 못해도 상태를 이해할 수 있다.

### P2 — 문구와 용어 정리

- `학생별 위치·pair 조건` → `학생별 위치 및 짝 조건`
- `과거 이력을 반영한 후보 생성` → `이전 자리와 겹치지 않게 새 배치를 만듭니다`
- `자리표 보기` → `현재 자리표 열기` 또는 `자리표 보기·인쇄`
- `확정 배치 · 21명`에는 최근 확정일이나 배치 이름을 함께 표시한다.
- 헤더와 상태 영역에 중복된 `2026학년도` 표기를 정리하고, 헤더의 연도 배지는 학년도 선택 기능으로 검토한다.

완료 조건:

- 화면에 불필요한 영문 혼용이 없다.
- 버튼 문구만 읽어도 실행 결과를 예상할 수 있다.

### P2 — 밀도, 대비, 접근성 개선

- 반복 카드의 높이와 내부 여백을 줄여 주요 기능이 첫 화면에 더 많이 보이게 한다.
- 본문 텍스트와 연한 버튼의 명도 대비를 WCAG 기준으로 확인한다.
- 키보드 포커스, 호버, 활성, 비활성 상태를 명확하게 제공한다.
- 모든 클릭 대상은 충분한 크기를 확보하고 카드 전체 클릭 여부를 일관되게 적용한다.

완료 조건:

- 일반 데스크톱 화면에서 핵심 기능이 과도한 스크롤 없이 보인다.
- 키보드만으로 주요 기능을 실행할 수 있다.
- 프로젝터나 밝은 환경에서도 텍스트와 버튼을 쉽게 구분할 수 있다.

## 권장 첫 화면 구성

```text
학급명 · 학년도 선택

학생 수 · 좌석 수 · 조건 수 · 최근 확정일

[새 자리배치 만들기]

준비 설정
학생 명단 → 교실 배치 → 자리배치 조건

현재 자리
자리표 미리보기 · 인쇄 · 수정

기록 및 기타
자리 기록 · 급식실 · 급식실 기록
```

## 권장 작업 순서

1. 실제 데이터에 따른 상태 문구와 버튼 분기 구현
2. `새 자리배치 만들기`를 첫 화면의 기본 행동으로 변경
3. 준비 설정과 기록/기타 기능을 목적별로 재배치
4. 문구와 용어 통일
5. 화면 밀도, 색상 대비, 키보드 접근성 검증
6. 데스크톱과 좁은 화면에서 사용자 흐름 재검토
