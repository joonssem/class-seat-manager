# 자리표 화면 돌아가기 버튼 오류 기록

작성일: 2026-09-01

## 사용자 제보

- 자리표 화면에서 `돌아가기` 버튼이 작동하지 않는다.
- 이번 단계에서는 사용자의 요청에 따라 코드 수정이나 동작 변경을 하지 않는다.

## 재현 정보

- 화면: 자리표 화면
- 대상 입력: `돌아가기` 버튼
- 기대 동작: 자리표 화면에 진입하기 전 화면으로 이동
- 실제 동작: 버튼 입력 후 화면 이동이 발생하지 않음
- 입력 방식: 미확인(마우스/터치 클릭인지, 키보드 Tab 후 Enter/Space인지 추가 확인 필요)

## 점검 계획

1. 자리표 화면의 버튼이 실제로 렌더링되는지 확인한다.
2. 버튼의 `onClick`, `disabled`, `tabIndex`, `aria-disabled` 상태를 확인한다.
3. 상위 요소 또는 다른 레이어가 버튼의 pointer/click 이벤트를 가로채는지 확인한다.
4. 자리표 진입 경로별 반환 대상 상태가 올바르게 전달되는지 확인한다.
5. 마우스·터치·키보드 입력을 분리해 재현한 뒤 원인 확정 후 수정한다.

## 수정 내용

- 자리표 헤더를 모드 전환 영역보다 높은 레이어로 배치해 버튼이 다른 요소에 가려지지 않도록 했다.
- `돌아가기` 클릭 핸들러에서 기본 동작과 이벤트 전파를 명시적으로 제어한 뒤 반환 콜백을 호출하도록 했다.
