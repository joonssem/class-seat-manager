# 5회차 과거 자리 기록 미리보기 구현 기록

> 참고: 이 문서는 작성 시점의 기록이다. "다음 단계"·"아직 진행하지 않음" 표현은 이후 구현으로 대부분 완료되었다. 최신 상태는 `23a-plan-completion-audit.md`와 `28-top-level-review-and-decision.md`를 기준으로 한다.

작성일: 2026-09-01

## 이번 단계

P0 입력 검증 결과를 자리 기록 화면에 연결했다.

## 제공 기능

- 1~5회차별 입력 영역
- 회차별 배치일 입력
- 학생 이름 + 자리번호 붙여넣기
- 탭/쉼표 입력 해석
- 매칭 성공 건수 표시
- 미등록 학생·동명이인·없는 자리·중복 배정 오류 표시
- 5회차 전체가 저장 가능한지 요약 표시

## 저장 정책

- 이번 단계에서는 미리보기만 제공한다.
- DB에는 아무 기록도 저장하지 않는다.
- 5회차 일괄 저장은 모든 검증이 통과한 뒤 다음 단계에서 연결한다.

## 검증 결과

- 타입 검사 통과
- 전체 테스트: 22개 통과, 1개 스킵
- 프로덕션 빌드 통과

다음 단계는 미리보기에서 검증된 5회차를 하나의 transaction으로 저장하는 기능이다.
