# 후보 평가 UI 구현 기록

작성일: 2026-09-01

## 구현 내용

- 후보 평가에 조건별 요약 데이터를 추가했다.
- 후보 화면에 현재 점수와 조건별 통과·주의·위반 상태를 표시한다.
- 같은 자리, 과거 근접, 성별 인접, 학생 위치, pair 거리, 위치 경험을 모두 요약한다.
- 조건 적용 개수와 penalty를 함께 표시한다.
- 배치표에서 학생을 교체하면 `seating:evaluate`를 다시 호출해 점수를 갱신한다.
- 재평가 중 상태를 화면에 표시한다.

## 검증 결과

- 타입 검사 통과
- 전체 테스트 25개 통과·1개 스킵
- 프로덕션 빌드 통과
