# 미적용 계획 전체 점검 기록

작성일: 2026-09-01

## 완료된 계획

- 1학기 5회차 과거 자리 기록 입력 형식·이름/자리번호 매칭·미리보기·일괄 transaction 저장
- 학기별 자리 기록·학생별 경험 조회 및 추천 이력 연계
- `가능한 한 멀리` pair 조건 점수 반영
- 자리표 180도 점대칭 표시와 돌아가기 버튼 보완
- 자리·학생 외래키 동기화 및 기존 위치 snapshot 보완 집계
- 이미지 기준 교실 좌석 1~21 배치 구성

## 문서 표현만 갱신이 필요한 항목

- 11~15번 문서의 “다음 단계”와 “아직 진행하지 않음” 표현은 구현 완료 상태와 맞지 않는 과거 기록이다.
- 실제 코드와 최신 완료 내용은 14, 16, 18, 19, 20, 22번 기록을 기준으로 한다.

## 사용자 입력이 있어야 완료되는 항목

- 실제 1학기 5회차 학생 이름·자리번호 원본 데이터
- 각 회차의 실제 배치일

위 데이터는 현재 작업 폴더에 없으며, 임의로 생성하면 과거 기록을 오염시키므로 입력 전까지 보류한다.

## 검증

- 타입 검사 통과
- 전체 테스트 25개 통과·1개 스킵
- 프로덕션 빌드 통과
