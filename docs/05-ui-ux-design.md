# 05. UI·UX 설계

## 디자인 원칙

수업 중에도 빠르게 이해하도록 큰 클릭 영역, 짧은 문장, 명확한 현재 학년도와 저장 상태, 되돌릴 수 있는 draft, 확정 전 확인을 우선한다. 색상만으로 상태를 전달하지 않고 아이콘·문구를 함께 사용한다. 학생 이름은 항상 정상 방향으로 읽힌다.

## 공통 구조

상단에는 현재 학년도, 저장 상태, 백업 메뉴를 둔다. 좌측 또는 홈에는 대시보드·현재 자리·새 자리·급식실·학생 관리·기록·교실 설정을 둔다. modal은 짧은 확인에만 사용하고 복잡한 편집은 전체 화면으로 한다.

## 화면 정의

| 화면 | 목적 / 주요 정보 | 행동·다음 화면 | 오류·빈 상태 |
|---|---|---|---|
| 대시보드 | 현재 학년도, 학생 수, 자리변경 횟수, 현재 자리, 급식실, 학생 관리, 교실 설정 카드 | 카드 클릭으로 각 화면 이동 | 최초 설정 체크리스트 |
| 최초 설정 | 학년도·명단·교실을 순서대로 완성 | 저장 후 대시보드 | 누락 단계와 이유 표시 |
| 학생 관리 | 명단, 번호, 이름, 성별, 재학 상태, 전입/전출 | 추가·붙여넣기·CSV/Excel, 학생 상세 | 중복 번호/빈 이름 행 오류 |
| 교실 배치 편집 | 캔버스, 책상·칠판·문, 좌표와 태그 | 추가·이동·크기·태그 확인 | 좌석 없음·겹침 경고 |
| 현재 자리 | 확정 배치와 마지막 변경일 | 새 자리, 출력, 전체화면 | 현재 확정 배치 없음 |
| 새 자리 생성 | 활성 학생·좌석, 조건 요약, 가중치 프로필 | 조건 확인→계산→후보 비교 | 좌석 부족·필수 충돌 |
| 후보 3개 비교 | 후보 점수, 항목별 penalty, 차이 | 후보 선택→수동 수정 | 3개 미만이면 사유 표시 |
| 자리 수동 수정 | 드래그·교환, 미배정/중복 상태 | 재평가→확정 | hard 위반 시 확정 차단 |
| 자리 확정 | 최종 요약과 이력 메모 | 확정 저장→자리표 | “이력에 저장” 확인 |
| 학생별 조건 | 위치 태그와 강도 | 저장 후 새 자리 생성 | 태그 없음·required 부족 |
| 학생 pair 조건 | 두 학생, 관계·거리·강도 | 추가·수정·비활성화 | 동일 학생/중복 pair 차단 |
| 자리 기록 | 학년도별 회차·날짜·메모 | 상세·자리표·통계 | 기록 없음 |
| 학생 자리 경험 | 선택 학생의 영역·좌석·근접 통계 | 학생 변경·전체 비교 | 신규 학생은 데이터 부족 안내 |
| 급식실 | 줄서기와 22자리 결과 | 생성→수정→확정 | 인원/인솔 설정 부족 |
| 인솔 학생 설정 | 현재 학기 회장·부회장 4명 | 저장 후 급식실 | 4명 초과·중복 경고 |
| 출력 미리보기 | 학생용/교사용/급식실 결과 | 인쇄/PDF | 프린터 없음·페이지 나눔 안내 |
| 학년도 관리 | 생성·전환·보관 상태 | 전환 확인 | 확정되지 않은 draft 경고 |
| 백업/복원 | 내보내기, 파일 선택, 검증 결과 | 복원 전 확인 | 버전·무결성 오류 |

## 드래그 앤 드롭

교실 편집은 책상 요소를 격자에 강제하지 않고 정규화 캔버스에서 이동·크기 조절한다. 선택된 요소에는 좌표와 태그 패널을 함께 보여준다. 자리 수정은 학생 카드/자리 간 drag, 동일 자리 drop 시 교환, 빈 자리 drop 시 이동을 지원한다. 키보드 접근을 위해 선택 후 방향키 이동과 “학생 A와 B 교환” 메뉴를 제공한다. 드래그 중에는 임시 상태만 바꾸고 저장 버튼 또는 자동 저장 시점에 서비스로 전송한다.

## 상태·오류·실수 방지

draft 배치와 확정 이력을 시각적으로 구분한다. 계산 중에는 중복 실행을 막고 취소를 제공한다. 브라우저 뒤로가기나 화면 이동 시 미저장 변경을 경고한다. 확정 버튼에는 대상 학생 수, 좌석 수, 위반 수, 이력 저장 사실을 표시한다. 삭제보다 전출/비활성화를 기본 행동으로 한다.

## 출력 방향

학생용은 학생이 자기 자리에서 칠판을 보는 방향을 기준으로 좌석을 배치한다. 교사용은 칠판을 등지고 학생을 보는 방향으로 좌우·앞뒤 배열을 반전한다. 텍스트를 180도 회전하지 않는다. 인쇄 CSS와 PDF 미리보기는 동일한 렌더 모델을 사용하고, 이름 표시 방식은 AppSettings에서 선택한다.
