# 관계 조건을 반영하는 모둠 자리배치

작성일: 2026-10-22

## 사용 방법

대시보드 → 모둠 자리 만들기에서 시작한다. 기본 구성은 4·4·4·4·5명이며, 모둠별 인원을 바꿀 수 있다(모둠당 3~5명, 최대 8개). 합계는 재학생 수와 같아야 한다.

기존에 저장한 학생 간 관계 조건과 위치 조건을 불러온다. 별도 관계 입력은 필요 없다. 특정 학생들을 서로 다른 모둠에 두려면 분산 학생으로 선택한다. 선택 인원은 모둠 수를 넘을 수 없다.

생성 후 모둠별 학생 선택에서 두 학생을 교환할 수 있다. 모든 교환 후 조건을 다시 평가하며 필수 조건 충돌이 있으면 확정 저장할 수 없다. 자리표 미리보기에서 인쇄·PDF 저장을 사용할 수 있다. 미리보기는 아직 저장하지 않은 구성도 출력할 수 있다.

확정 저장하면 교실 책상이 두 쌍의 마주 보는 자리와 끝자리(5명 모둠) 형태로 바뀌고, 날짜에 맞는 학기의 확정 이력이 생성된다. 칠판·문 요소와 기존 자리 기록은 보존한다. 교실 배치와 자리 기록은 한 트랜잭션에서 저장하여 실패 시 함께 원복한다. 교실 편집 화면에서 책상 위치를 추가로 조정할 수 있다.

## 평가 규칙과 한계

- 관계 조건은 현재 앱이 지원하는 인접 금지·최소 거리·가능한 한 멀리 조건이다. 친밀도나 선호 친구를 추정하지 않는다.
- 모둠 활동에서는 전체 구성원이 상호작용하므로 필수 관계 조건은 기존 거리 평가에 더해 같은 모둠 배정을 금지한다. ‘가능한 한 멀리’도 필수라면 같은 모둠을 금지하지만, 거리 자체의 전역 최댓값을 필수로 요구하지 않는다.
- 가급적·선호 관계 조건은 같은 모둠에 들어갈 때 감점하고 경고한다. 모둠이 달라도 인접·최소 거리 조건을 평가한다.
- 학생별 위치 조건은 새 모둠 책상의 실제 좌표와 기존 문 위치를 기준으로 평가한다. 앞·중간·뒤 조건에 따라 구성원이 모둠 사이에서 이동할 수 있다.
- 성비는 전체 성비에 비례하도록 감점으로 조정한다. 남 9명·여 12명, 4·4·4·4·5명 구성에서 별도 관계 충돌이 없으면 남학생 수는 1·2·2·2·2명 구성이 된다. 성비는 필수 조건을 깨면서까지 맞추지 않는다.
- 분산 학생 선택은 현재 구성에 대한 필수 조건이며 기존 관계 조건을 덮어쓰지 않는다. 다음 구성 시 다시 선택한다.
- 이번 기능은 과거 배치 반복 감점을 사용하지 않는다. 기존 개별 자리 추천 엔진과 평가 점수는 별도로 유지한다.
- 고정된 횟수의 다중 시작 교환 탐색을 사용한다. 충돌이 남으면 구성 불가능을 증명한 것은 아니므로 재생성·수동 교환·조건 검토가 필요하다.

## 검증

- TypeScript 타입 검사 통과.
- 전체 기본 테스트 84개 통과(시스템 Node에서 네이티브 통합 테스트 4개 제외).
- Electron 환경 SQLite 통합 테스트 4개 모두 통과. 저장 중 오류 발생 시 배치와 이력의 동시 원복 확인.
- 21명 배정, 성비, 5명 분산, 관계·위치 조건, 충족 불가능한 조건 표시, 수동 교환, 잘못된 인원 입력, 저장 API 연결 검증.
- Electron production build 통과.
- Windows NSIS 설치 파일과 `dist/win-unpacked` 실행 파일 생성 완료.

실제 학생 DB를 자동 수정하거나 새 배치를 확정하지 않았다. 실제 프린터 출력은 별도 확인이 필요하다.
